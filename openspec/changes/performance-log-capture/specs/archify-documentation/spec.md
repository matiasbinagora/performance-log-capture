## ADDED Requirements

### Requirement: Visual architecture documentation
The project SHALL provide English Archify documentation for the component architecture and manual demo sequence.

#### Scenario: Component diagram
- **WHEN** a user opens the architecture diagram
- **THEN** it shows the catalog, run artifacts, agents, Graphify, dashboard, and Playwright

#### Scenario: Sequence diagram
- **WHEN** a user opens the demo-flow diagram
- **THEN** it shows manual activation from performance run through log analysis and QA evidence
